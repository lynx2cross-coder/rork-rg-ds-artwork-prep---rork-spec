ROM Art Prep
ROM Art Prep is a standalone Android utility for preparing artwork and metadata for ROM collections.
It scans ROM locations, identifies systems and games, finds artwork, and stores it with the appropriate ROMs for use with compatible frontends.
Features
- 📁 Multiple saved ROM locations, including internal storage and SD cards
- 🎮 Automatic system and game detection
- 🖼️ Artwork scraping and manual artwork selection
- 🎯 Platform filters in the Artwork gallery
- 📋 gamelist.xml generation and cleanup
- 🚫 Persistent ignored-file support
- 🗑️ Optional orphaned-artwork cleanup
- 💾 Artwork remains associated with its original ROM location
- 📱 Android storage permission support
Artwork Sources
- Hasheous
- Libretro Thumbnails
- TheGamesDB
- ScreenScraper
3DS Support
Supported game formats:
- .3ds
- .cia
- .cci
Common 3DS system files can be added to the Ignored Files list.
